# Anime-Recommendation-System

* Projeto pessoal de recomendação de animes presentes no site MyAnimeList.
* O objetivo é realizar análises entre os TOP 1000 animes deste site, e com base em seus dados (gêneros, sinopse, background, studio, demografia, etc.) recomendar para usuários aqueles animes que mais se assemelham com seus gostos.
